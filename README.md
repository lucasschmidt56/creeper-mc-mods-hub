## What Creeper Is

Creeper is a browser-facing catalog built around Minecraft add-ons. It groups mods and maps so players can scan options, read item details, and reach downloadable world content from one site.

The project targets anyone who prefers a simple web interface for discovering Minecraft expansions. Ongoing work centers on keeping listings current and growing the set of mods and maps over time.

## Getting Started

Load the live collection in any modern browser:

1. Go to [Creeper](https://lucasschmidt56.github.io/creeper-mc-mods-hub/).
2. Move through the mod or map sections.
3. Open an entry to read what the site shows for that item.
4. Use the download or access steps listed on the page.

Clone the repo if you want the files on your machine:

```bash
git clone https://github.com/lucasschmidt56/creeper-mc-mods-hub.git
cd REPO
```

For a static deploy, open the primary HTML file locally or serve the folder with a lightweight web server. Keep Minecraft downloads sorted by kind—for example `mods/` for mod packages and `maps/` for world files.

## FAQ

### How frequent are updates?

There is no fixed release cadence. Mods and maps are added or refreshed whenever the collection grows.

### Can the project be customized?

Yes. Contributors may reshape the site layout, styling, or how Minecraft content is grouped.

### Does every listing match my Minecraft version?

No guarantee. Support is per item and depends on the version that content expects. Verify before you install.

### How should downloads be organized locally?

Split files by type: put mods under `mods/` and maps under `maps/`. Match whatever layout your Minecraft client or launcher expects.

### Is a particular Minecraft edition called out?

The project profile does not name an edition. Check each mod or map for edition and version requirements.

### How do I open the collection?

Browse Minecraft resources on the [Creeper website](https://lucasschmidt56.github.io/creeper-mc-mods-hub/).
